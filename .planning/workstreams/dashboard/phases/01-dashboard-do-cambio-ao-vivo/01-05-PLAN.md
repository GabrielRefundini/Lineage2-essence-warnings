## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| navegador -> servidor local | Qualquer aba pode falar com o endereco de retorno local; a pagina que emite o pedido nao e necessariamente a nossa |
| arvore do repo -> resposta HTTP | O arquivo de segredo com o token do Chatwoot mora na raiz da arvore que o processo enxerga |
| dois processos -> uma porta | Dois cliques no lancador criam dois servidores; sem defesa, o navegador fala com o vencedor da corrida |
